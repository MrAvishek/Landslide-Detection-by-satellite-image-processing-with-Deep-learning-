QUICK GUIDE

How to run an analysis

  1. Choose the satellite feature file.This HDF5 file is required for U-Net inference.
  2. Add a ground-truth mask when available.The reference mask is optional. Without it, the dashboard reports prediction-derived statistics only.
  3. Set the threshold and run.The threshold converts probability output into a binary predicted mask.
  4. Review the output.When a reference mask is supplied and accepted by the API, overlap and classification metrics can be shown.

The backend must support the mask_file form field and return the relevant evaluation metrics for the evaluation panel to populate.
